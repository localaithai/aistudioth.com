# AI Studio TH

Thai-first, spec-led desk-side AI rig builds for developers, researchers, and small technical teams that run models locally.

## Development

```bash
pnpm install
pnpm build
```

The project uses Astro static output; React ships only as client islands. The production output is written to `dist/`.
