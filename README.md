# AI Studio TH

Thai-first, spec-led desk-side AI rig builds for developers, researchers, and small technical teams that run models locally.

## Development

```bash
npm install
npm run build
```

The project uses Next.js static export. The production output is written to `out/`.

## Routes

- `/`
- `/builds`
- `/models`
- `/benchmarks`
- `/about`
- `/ecosystem`
- `/contact`
