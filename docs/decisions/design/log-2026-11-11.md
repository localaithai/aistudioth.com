# Design log, 2026-11-11

## Studio-gear identity replaces the Apple-style blue and white

**Context.** The site shared its look with the cloud brand: white ground, one
blue, pill buttons, icon cards, a kicker above every section. It read as a SaaS
template, not as the door for people who will sit at the machine, and the
portfolio needs each brand to be told apart at a glance. The user asked for a
full UI revamp across the acquisition sites.

**Chosen.** The rig is presented the way studio hardware presents itself: an
aluminium ground, ink legends, one signal red and condensed plate numerals.
Copy, routes, metadata and structured data did not change.

- Colour. `page #e4e5e7`, `panel #f1f2f3`, `surface #fbfbfc`, `ink #131416`,
  `ink-2 #474a4f`, `brand #c8102e`, `deck #17181a`. Measured contrast: ink on
  page 14.62, ink-2 on page 7.06, brand on page 4.67, white on brand 5.88,
  on-brand-2 `#ffe1e4` on brand 4.80, deck-ink on deck 15.85, deck-ink-2 on deck
  7.88, clip `#f0353f` on deck 4.47 (non-text), clip-ink `#ff7a82` on deck 7.07,
  input edge `#7c8087` on white 3.84. Red is reserved for the primary action,
  the legend LED square, over-capacity meters and the footer ground.
- Type. K2D for Thai and mixed text, because one family draws both scripts in a
  squared, engineered hand. Big Shoulders Display for Latin-only readouts, the
  wordmark and page titles, because condensed heavy numerals read as an
  equipment plate. It has no Thai, so it never sets a string that can hold Thai.
- Memory as a level meter. `Meter` draws model weights against capacity from the
  figures already in `rig-data.ts`: a build's capacity on a 0 to 256 GB scale,
  and each model row against each memory size, turning red where the weights
  exceed capacity. The written verdict stays beside every meter, so colour is
  never the only signal. Benchmark meters are empty because nothing is measured.
- Layout. Ruled rows and plates with 1px ink borders replace identical card
  grids; builds are a rack of four units; the model table is the one dark band
  and reflows to stacked blocks below 1024px instead of scrolling sideways.
  Subpages open with the page name as a visible H1. Seven desk photographs from
  the site's own catalogue set carry the imagery, each captioned as illustrative.
- The footer is the red panel. Partner marks are multiplied onto the ground in
  one colour instead of sitting in white boxes.

**Rejected.** Keeping blue: two other brands in the portfolio use it. A dark
theme: four hardware-line siblings are dark, and the catalogue photography for
this brand is bright aluminium. Monospace for technical flavour: the readout
face does that job with more character and less cliche. Audio imagery, knobs or
waveforms: the gear reference is form only; the product is not a creator studio.
A numeric field for model memory in `rig-data.ts`: the meter parses the existing
string, so one value stays written once.

**Consequences.** `AnimatedLogo` and the gradient wordmark are gone. The hero
uses one photograph at every width. `site.themeColor`, the social card and the
favicon follow the new palette; the favicon URL and its query string did not
change.
