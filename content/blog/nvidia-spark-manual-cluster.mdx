## นักพัฒนาได้ทางเลือกอะไรเพิ่ม

NVIDIA ระบุการต่อ Spark แปดเครื่องแบบ manual ใน[ข่าว 21 ตุลาคม](https://blogs.nvidia.com/blog/local-ai-gtc-rtx-dgx-spark-station-sync/) ส่วน[พื้นหลังวันที่ 2 ตุลาคม](https://blogs.nvidia.com/blog/local-ai-dgx-spark-64gb-sync/) อธิบาย ConnectX-7 และรุ่น 64GB

สำหรับคนประกอบ rig การทดลองควรมีจุดหยุด ก่อนแตะเครือข่ายให้เก็บค่าที่ใช้อยู่และวิธีกลับสภาพเดิมไว้ อย่าเปลี่ยนจำนวนเครื่อง รุ่น runtime และโมเดลพร้อมกันจนแยกสาเหตุไม่ออก

## บันทึกการทดลองให้หาสาเหตุได้อย่างไร

แบบบันทึกนี้แยกชั้นของงาน เพื่อให้การเพิ่มเครื่องมีหลักฐานมากกว่าภาพว่าโปรเซสเริ่มแล้ว

| ชั้นที่ทดลอง | ค่าที่ตรึงไว้ | สิ่งที่เก็บกลับมา |
| --- | --- | --- |
| เครือข่าย | ผังสายกับค่าพอร์ต | ผลตรวจลิงก์และข้อผิดพลาด |
| ระบบ | OS กับแพ็กเกจ | รายการติดตั้งแต่ละเครื่อง |
| Runtime | วิธีแบ่งงานกับคำสั่ง | Log และหน่วยความจำสูงสุด |
| โมเดล | รุ่น precision และ input | เวลาจบกับคุณภาพคำตอบ |

## ควรเพิ่มเครื่องเมื่อใด

เพิ่มเมื่อรู้ว่าข้อจำกัดเดิมอยู่ที่ไหนและวัดผลการเปลี่ยนแปลงได้ ถ้ารันครั้งแรกยังทำซ้ำไม่ได้ ให้แก้ environment ก่อน แล้วจึงดูว่างานได้ประโยชน์จากการกระจายหรือไม่
