## ASUS B70 รุ่นนี้เกี่ยวอะไรกับพื้นที่ใน rig

[ASUS ประกาศวันที่ 23 ตุลาคม](https://www.mynewsdesk.com/de/asus-dach/pressreleases/eng-asus-announces-ugen-intel-arc-pro-b70-32gb-ai-accelerator-cards-3474064) ขาย UGen B70 ในเยอรมนี ออสเตรีย และสวิตเซอร์แลนด์ โดย[หน้าสินค้า ASUS](https://www.asus.com/motherboards-components/ai-accelerator/ugen/ugen-arc-pro-b70-32g/) ระบุโครงสองสล็อต แบบ blower และกำลังไฟ 310W

[ประกาศ Intel เมื่อ 25 มีนาคม](https://www.intel.com/content/www/us/en/newsroom/news/client-computing/intel-core-ultra-series-3-with-vpro-powers-next-gen-pcs-on-18a.html) เป็นบริบทชิปที่มีอยู่ก่อนแล้ว ข่าวขายครั้งนี้ยังไม่ใช่ผลทดสอบว่าเมนบอร์ดหรือเคสของคุณรองรับหลายการ์ด

## ต้องวาดแผนก่อนเสียบการ์ดอย่างไร

ตารางนี้เป็นข้อวิเคราะห์สำหรับทำ build sheet ให้เปิดคู่มือของเมนบอร์ด เคส PSU และการ์ดรุ่นที่จะใช้ แล้วเขียนตำแหน่งจริงก่อนซื้อชิ้นส่วนเพิ่ม อย่าตัดสินจากจำนวนช่องที่มองเห็นเพียงอย่างเดียว

| ส่วนที่ตรวจ | บันทึกลง build sheet | สิ่งที่ลองบนเครื่องจริง |
| --- | --- | --- |
| ระยะและสล็อต | ตำแหน่งการ์ดกับพื้นที่หัวต่อ | ไม่ชนอุปกรณ์และยังถอดซ่อมได้ |
| เลน PCIe | ผังแบ่งเลนตาม CPU และคู่มือบอร์ด | ตรวจ link ที่ได้หลังใส่ครบ |
| อุปกรณ์ร่วม | NVMe การ์ดเครือข่าย และช่องที่ใช้ร่วม | ทุกอุปกรณ์ยังถูกตรวจพบ |
| ไฟ | รุ่น PSU สาย และหัวต่อตามคู่มือ | สายไม่ตึงและไม่มีโหลดเกินขอบเขต |
| ทางลม | ช่องรับลม ทางออก และระยะรอบเครื่อง | อุณหภูมิกับความถี่ระหว่างโหลดต่อเนื่อง |

เริ่มจากการ์ดเดียว เก็บรายการอุปกรณ์และผลของงานเดิม แล้วเพิ่มอีกการ์ดโดยยังไม่เปลี่ยน runtime พร้อมกัน วิธีนี้ช่วยแยกปัญหาประกอบเครื่องออกจากปัญหาการแบ่งงานของโปรแกรม

## จะรู้ได้อย่างไรว่า build พร้อมใช้งาน

### เก็บผลทั้งก่อนและหลังใส่อุปกรณ์ครบ

ทดสอบหลังใส่ไดรฟ์และการ์ดเสริมครบแล้วด้วย หากตอน bench ถอดอุปกรณ์ออก ให้เขียนไว้ เพราะจำนวนเลนหรือช่องทางลมอาจต่างจากเครื่องใช้งานจริง ตรวจขณะเครื่องทำงานต่อเนื่องและดูความแกว่ง ไม่สรุปจากช่วงแรกที่ยังเย็น

หลายการ์ดไม่ได้ทำให้ทุกโปรแกรมเห็นหน่วยความจำก้อนเดียว ต้องระบุวิธีแบ่งงานของ runtime แยกในสมุด build ผลทดสอบบนบอร์ดหนึ่งจึงยังใช้รับรองอีกบอร์ดไม่ได้
